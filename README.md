# Sana Vita — головна сторінка

Сайт медичного центру Sana Vita (Одеса), зверстаний за макетом у Figma.

Чистий HTML + CSS + JavaScript, без збірки. Щоб переглянути локально — відкрийте `index.html` або запустіть:

```bash
python3 -m http.server 8000
```

## Що є
- адаптивна верстка (десктоп 1440 px, планшет, мобільний)
- липка шапка, перемикач мови, мобільне меню
- інтерактивні вкладки цін за напрямами
- слайдер лікарів, розгортання відгуків, анімовані лічильники
- Google-мапа, копіювання адреси, форма запису з валідацією

Шрифти: e-Ukraine, Ermilov (у папці `fonts/`).
